# YouTube Music Direct 0.1.0

Прямой каталог YouTube Music и загрузка Opus/AAC через InnerTube/Googlevideo.
Форк ytmusic-spotiflac 2.4.6. Удалены Zarz/Cobalt, yt1d, внешние серверы
получения PO Token и дополнительное обогащение метаданных через Deezer.
Сохраняются поиск, ссылки, коллекции, артисты и рекомендации upstream.

Импорт: `build/ytmusic-direct-0.1.0.sflx`. По умолчанию PO Token Mode: off.
Если сервис требует действующий GVS PO Token, его можно вручную указать
в секретной настройке Manual GVS PO Token и выбрать manual. Автоматической
выдачи/обновления токенов и входа в аккаунт нет. Токен может быть привязан
к клиенту, видео и сессии; произвольный токен не гарантирует работу.

Если прямой поток недоступен, расширение возвращает ошибку без попыток
обращения к сторонним загрузчикам. Потоки скачиваются только с HTTPS
поддоменов googlevideo.com. Качество исходное, lossless не обещается.

Версия экспериментальная. Проверены офлайн-контракты и исключение резервных
сервисов; реальное скачивание в приложении не проверено. YouTube может
потребовать вход, PO Token или изменить протокол. Эти ограничения не скрываются
под резервным запросом к Zarz.

Крупный index.js сохраняет структуру upstream. Авторство и лицензии
указаны в THIRD_PARTY_NOTICES.txt, LICENSE, COPYING, NOTICE.
