# Amazon Music Direct 0.1.0

**Только каталог и метаданные. Скачивания аудио нет.**

Отдельный форк Amazon 2.3.19 из Mornye-Extension. Сохранены прямые запросы
Amazon Music Web: поиск, ссылки, треки, альбомы, артисты, плейлисты и домашняя
лента. Удалены код скачивания через Zarz, signed session, проверка сервера
Zarz и сопоставление через сторонние сервисы. В manifest только
`metadata_provider`; аккаунт для скачивания или подписку расширение не запрашивает.

Полное аудио Amazon использует DRM и требует лицензированного CDM и
интеграции с воспроизведением. Такой возможности в текущем JS host API нет.
Это ограничение нельзя исправить заменой адреса загрузчика. Превью не
выдаются за полные треки. Документация Amazon:
https://developer.amazon.com/docs/music/playback_overview.html

Импорт: `build/amazon-direct-0.1.0.sflx`. Настройка Home feed country задаёт
регион рекомендаций. Веб-API может менять ответы и требовать вход в браузере;
реальная работа с аккаунтом в этой версии не проверена.

Приложение может предложить другие download-провайдеры для найденных треков.
Это уже запросы других расширений, а не прямое скачивание из Amazon.
Чтобы весь маршрут не использовал Zarz, отключите upstream-провайдеры,
которые к нему обращаются.

Крупный файл index.js сохраняет структуру upstream; авторство и LGPL-3.0-only
сохранены в THIRD_PARTY_NOTICES.txt, LICENSE, COPYING, NOTICE.
