# VK Музыка для Mornye / LibreMusic

Экспериментальное расширение: поиск, треки, альбомы и плейлисты VK.
Поддерживаются ссылки `vk.com/audioOWNER_ID`,
`vk.com/music/album/OWNER_PLAYLIST`, `vk.com/audio_playlistOWNER_PLAYLIST_KEY`
и соответствующие адреса vk.ru. ID трека содержит владельца и ID аудио:
например `-123_456`. Ключ доступа приватного плейлиста сохраняется.

## Настройка

Нужны музыкальный `access_token` своего аккаунта и соответствующий
`device_id` той же мобильной сессии. Введите их в секретные настройки
расширения. При необходимости укажите исходный User-Agent сессии.
Обычный публичный токен VK API может не иметь доступа к `audio.*`.
Расширение не получает токен по паролю и не создаёт мобильную сессию.
При ошибках 1114/1117 обновите сессию в клиенте, которым она получена.

Контракт сессии и API:
[MusiMuX API](https://github.com/MuXolotl/MusiMuX/blob/main/docs/API.md).
API: `api.vk.ru/method/*`, версия 8.154. Токен передаётся в теле POST только
API, без добавления к запросам аудио, HLS-сегментов и ключей.

## Аудио

Сохраняется исходный MP3 либо конечный HLS с MPEG-TS сегментами.
HLS собирается и перепаковывается FFmpeg в M4A без перекодирования.
Поддерживается AES-128/CBC с ключом, предоставленным самим потоком.
Для HLS нужен рабочий FFmpeg в сборке приложения. Live, SAMPLE-AES,
DRM, fMP4/MAP, BYTERANGE и discontinuity не поддерживаются.
Длительность HLS сверяется с метаданными с допуском 10 секунд.
Битрейт 320 и lossless не обещаются. Временные HLS-файлы удаляются.

Плейлисты ограничены 2000 треками; поиск первой страницей до 100 записей.
Версия 0.1.0 проверена офлайн. Совместимость с реальной сессией и реальным
CDN пока не подтверждена; сервис может изменить домены и формат ответа.

Сборка: `python3 extensions/build.py vk-music`.
Установка: импортировать `.tmp/extensions/vk-music-0.1.0.sflx` в расширениях.
