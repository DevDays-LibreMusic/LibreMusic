# Deezer Direct

Отдельное экспериментальное расширение Mornye/LibreMusic. Поиск, метаданные,
альбомы, публичные плейлисты и скачивание доступного своему аккаунту аудио.
Не использует Zarz, внешний resolver, shared ARL или подписанные сессии Zarz.
Исходное upstream-расширение Deezer остаётся отдельным и не изменяется.

## Настройка

1. Войдите в свой аккаунт на https://www.deezer.com в браузере.
2. В инструментах разработчика откройте Application/Storage > Cookies > Deezer.
3. Скопируйте только значение cookie `arl` (192 шестнадцатеричных символа).
4. Импортируйте `build/deezer-direct-0.1.0.sflx` в приложении.
5. В секретной настройке ARL вставьте значение и включите расширение.

ARL даёт доступ к сессии аккаунта. Не отправляйте его в чат, не коммитьте
и не вставляйте полный заголовок Cookie. Истёкший ARL заменяется вручную.
Логин по паролю и автоматическое обновление ARL не реализованы.

Качество выбирается явно: MP3 128, MP3 320, FLAC. Полнота аудио и качество
определяются аккаунтом, подпиской, регионом и доступностью трека. Расширение
не понижает качество автоматически и не использует превью в качестве трека.
Параметры FLAC читаются из файла; Hi-Res не обещается.

## Прямой протокол

- `api.deezer.com`: поиск и публичный каталог.
- `www.deezer.com/ajax/gw-light.php`: `deezer.getUserData` с cookie ARL,
  затем `song.getData` с токеном CSRF для получения токена трека.
- `media.deezer.com/v1/get_url`: license token и track token, только `FULL`
  и конкретный выбранный формат. ARL к этому запросу не добавляется;
  cookie jar очищается после запросов gateway.
- `*.dzcdn.net`: скачивание без добавления токенов и cookies расширением.
- `file.transformPatternedBlocks`: локальная обработка BF_CBC_STRIPE
  (Blowfish CBC, каждый третий полный блок по 2048 байт).
- `ffmpeg.getInfo`: проверка кодека и доступной длительности готового файла.
  Временный зашифрованный файл удаляется при успехе и ошибке.

Сессия и токен трека получаются заново для каждой загрузки. ARL хранится
в секретных настройках приложения, остальные данные аккаунта не сохраняются.

Контракт исследован по [orpheusdl-deezer](https://github.com/TheKVT/orpheusdl-deezer/blob/master/dzapi.py).
Код блочной обработки адаптирован из Mornye-Extension; лицензия LGPL-3.0-only
и авторство сохранены в THIRD_PARTY_NOTICES.txt и лицензиях пакета.

## Ограничения и проверка

Версия 0.1.0: проверены офлайн-контракты с моделированием ответов Deezer.
Реальная авторизация и загрузка не проверены, поскольку ARL пользователя
не предоставлен. Неофициальный API может измениться или отклонить запрос
с проверкой браузера. Такие проверки автоматически не обходятся.

Поддерживаются полные ссылки `/track/ID`, `/album/ID`, `/playlist/ID`
с необязательным префиксом языка. Короткие ссылки, артисты, личные закрытые
плейлисты, рекомендации и сопоставление с треками других сервисов не реализованы.
Поиск: первая страница до 100 треков. Коллекции: до 2000 треков, с пагинацией
и явной ошибкой при неполном списке.

```sh
node extensions/deezer-direct/test.cjs
python3 extensions/build.py deezer-direct --output-dir build
python3 extensions/build.py deezer-direct --output-dir build --check
```

Для проверки в приложении: ввести свой ARL, открыть полный URL трека Deezer,
скачать сначала MP3 128, затем доступные MP3 320/FLAC, проверить воспроизведение
и длительность. Отдельно проверить истёкший ARL и недоступное качество.
