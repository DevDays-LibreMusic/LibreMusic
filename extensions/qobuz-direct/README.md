# Qobuz Direct 0.1.0

Поиск, треки, альбомы, плейлисты и полное аудио напрямую через
`www.qobuz.com/api.json/0.2`. Zarz и серверы-посредники не используются.

Импорт: `build/qobuz-direct-0.1.0.sflx`. Настройки:

- `token`: user_auth_token своего аккаунта Qobuz.
- `appId`: идентификатор API-приложения.
- `appSecret`: соответствующий секрет приложения для подписания getFileUrl.

Используйте действующие согласованные параметры своего API-клиента. Токен
своей веб-сессии можно найти в инструментах разработчика браузера в запросах
Qobuz (X-User-Auth-Token). Это не пароль. App secret не равен токену пользователя
и не передаётся серверу напрямую: используется для MD5-подписи запроса.
Автоматическое извлечение app secret из сайта, вход по паролю и обновление
учётных данных не реализованы. Параметры нельзя отправлять в чат или Git.

Качества: MP3 320 (format 5), FLAC CD (6), до 96 kHz (7), до 192 kHz (27).
Фактическое разрешение зависит от релиза; оно измеряется по скачанному файлу.
Запрашивается полный поток выбранного формата, автоматического понижения нет.
Токен пользователя отправляется только API, не CDN.

Поддерживаются play.qobuz.com/open.qobuz.com track, album, playlist и
www.qobuz.com с языковым префиксом и slug. Поиск до 100 записей, коллекции
до 2000 с проверкой полноты. Источник протокола:
https://github.com/nathom/streamrip/blob/master/streamrip/client/qobuz.py

Версия экспериментальная: офлайн-тесты пройдены, реальная авторизация и
загрузка с аккаунтом не проверены. Для полного аудио нужен доступ аккаунта.
