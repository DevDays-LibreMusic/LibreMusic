# КИОН Музыка для Mornye / LibreMusic

Экспериментальный самостоятельный адаптер совместимого музыкального API:
поиск, ссылки music.kion.ru и music.mts.ru, треки, альбомы, плейлисты и MP3.
Режим «лучшее доступное» выбирает полный MP3 до 320 kbps, включая 192.
Режим 128 требует именно 128 kbps. Превью не скачиваются.

## Настройка

Войдите в свой аккаунт КИОН на сайте сервиса. В инструментах разработчика
браузера откройте Application / Local Storage и найдите `ya_token`.
Введите значение в секретную настройку расширения. Это токен аккаунта
КИОН; наличие расширения Яндекс Музыки не настраивает КИОН автоматически.
Способ описан в [Music Assistant](https://www.music-assistant.io/music-providers/kion-music/).

Настройка API выбирает адрес явно:

- `shared` (по умолчанию): `https://api.music.yandex.net`, как в коде
  [открытого провайдера](https://github.com/trudenboy/ma-provider-kion-music/blob/main/provider/constants.py).
- `mts-proxy`: `https://music.mts.ru/ya_proxy_api`, адрес из документации
  этого же проекта. Его текущая работоспособность не подтверждена.

Исходный проект расходится в коде и документации; поэтому автоматического
переключения адресов нет. Токен отправляется только выбранному API,
не CDN. После смены API перезагрузите расширение при необходимости.

Поддерживаются `/album/ID/track/ID`, `/track/ID`, `/album/ID`,
`/users/LOGIN/playlists/KIND`, `/playlists/UUID`. Гидратация плейлистов
выполняется пакетами по 50 треков. Неполный плейлист вызывает ошибку.
Качество и полный доступ зависят от аккаунта. Lossless не реализован.
Версия 0.1.0 проверена офлайн, загрузка с реальным аккаунтом КИОН не проверена.

Сборка: `python3 extensions/build.py kion-music`.
Установка: импортировать `.tmp/extensions/kion-music-0.1.0.sflx` в расширениях.
