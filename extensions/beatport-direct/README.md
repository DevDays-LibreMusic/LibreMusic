# Beatport Direct 0.1.0

Прямой API `api.beatport.com/v4`: поиск, треки, релизы, плейлисты и запрос
`catalog/tracks/{id}/download/`. Zarz и внешние загрузчики не используются.

Импорт: `build/beatport-direct-0.1.0.sflx`. Введите access token своего
аккаунта Beatport. Он должен иметь доступ к download API для выбранного
трека и качества. Каталожный токен без таких прав может искать треки,
но скачивание будет отклонено. Для streaming-доступа нужна соответствующая
подписка. Автоматического входа, получения или обновления токена нет.

Режимы: medium/AAC 128, high/AAC 256, lossless/FLAC. Ответ stream_quality
должен точно совпасть с запросом. Превью из sample_url не используются.
Проверяются кодек и длительность сохранённого файла, токен не отправляется
на CDN. HLS через /stream и DRM не поддерживаются.

Ссылки: beatport.com/track|release|playlist/slug/ID. Поиск первой страницей
до 100 записей, коллекции до 2000 с пагинацией и проверкой полноты.

Контракт прямого API исследован по исходному клиенту:
https://github.com/unspok3n/beatportdl/tree/878d3f61c5a98cffd43b9e0306b8cbc75488999e/internal/beatport

Экспериментальная версия: офлайн-тесты пройдены. Реальный токен, права
аккаунта и загрузка с CDN в приложении пока не проверены.
