# Звук для Mornye / LibreMusic

Экспериментальное расширение: поиск треков, ссылки `zvuk.com/track/ID`,
`/release/ID`, `/playlist/ID`, альбомы и плейлисты. Метаданные через GraphQL,
прямые аудиофайлы через Tiny API. Качество: mid (MP3 128), high (MP3 320),
flac. Доступность качества определяется аккаунтом и конкретным треком.

## Настройка

1. Войдите в свой аккаунт на https://zvuk.com.
2. Откройте https://zvuk.com/api/tiny/profile в том же браузере.
3. Скопируйте значение `token` в секретную настройку «Токен Звука».
4. Включите расширение. Для high/FLAC обычно нужна подписка.

Способ получения токена описан в [zvuk-music](https://github.com/trudenboy/zvuk-music#authentication).
Не используйте чужие токены. Расширение отправляет токен только в API Звука,
не добавляет его к запросам CDN. Вход и обновление токена выполняются вручную.

Поиск ограничен первой страницей. Плейлисты до 2000 треков; недостающие
метаданные считаются ошибкой. HLS и DRM-потоки не поддерживаются.
Версия 0.1.0 проверена офлайн; полный сценарий с аккаунтом не проверен.

Сборка из корня репозитория: `python3 extensions/build.py zvuk`.
Установка: импортировать `.tmp/extensions/zvuk-0.1.0.sflx` в разделе расширений.
