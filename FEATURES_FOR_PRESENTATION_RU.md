# LibreMusic — список фич для презентации

Список личных изменений `sliderer` составлен по истории Git и текущему коду.

## 1. Изменения sliderer, уже вошедшие в main

| Фича | Краткое описание для презентации |
|---|---|
| Собственный музыкальный сервер | Хранит и подготавливает музыку для прослушивания из приложения. |
| Потоковое воспроизведение с сервера | Позволяет начать слушать музыку без предварительного скачивания полного файла на телефон. |
| Серверная музыка в медиатеке | Сохраняет ссылки на серверные треки в общей библиотеке приложения. |
| Подключение разных источников к серверу | Получает музыку из HTTPS-ссылок, подключенного хранилища или NAS и расширений. |
| Фоновые серверные загрузки | Поддерживает очередь, прогресс, отмену и повтор загрузок; обработка продолжается после закрытия приложения. |
| Автоматическое продолжение музыки | Подбирает следующие треки по выбранному профилю и его ограничениям. |

## 2. Интеграции музыкальных сервисов, добавленные sliderer — уже в main

| Фича | Краткое описание |
|---|---|
| Яндекс Музыка | Поиск, треки, альбомы и плейлисты; получение доступного аккаунту MP3 до 320 кбит/с. |
| Звук | Поиск и работа с альбомами и плейлистами; поддержка MP3 и доступного аккаунту FLAC. |
| VK Музыка | Работа с каталогом, MP3 и поддерживаемыми HLS-потоками с сохранением в M4A. |
| КИОН Музыка | Поиск, обработка ссылок, альбомы, плейлисты и получение полного MP3. |
| Deezer Direct | Прямое подключение аккаунта для работы с каталогом и MP3/FLAC без внешнего сервиса-посредника. |
| YouTube Music Direct | Прямое получение каталога и аудио Opus/AAC без внешних сервисов загрузки. |
| Qobuz Direct | Подключение аккаунта и получение доступного ему аудио MP3/FLAC. |
| Tidal Direct | Подключение аккаунта и поддержка доступных незашифрованных потоков AAC/FLAC. |
| Beatport Direct | Работа с каталогом и AAC/FLAC при соответствующих правах аккаунта. |
| Amazon Direct | Прямой доступ к каталогу Amazon Music. Загрузка DRM-аудио не реализована. |

Доступность аудио в этих интеграциях зависит от сервиса, аккаунта и подписки.

## 3. «Новинки и тренды»

Раздел объединяет музыкальные рекомендации и связывает их с источниками воспроизведения.

| Фича | Краткое описание для презентации |
|---|---|
| Раздел «Новинки и тренды» | Новый экран для знакомства с актуальной музыкой, доступный в мобильной и десктопной навигации. |
| Общий чарт из пяти источников | Объединяет данные Apple Music, iTunes Charts, Deezer, Яндекс Музыки и Last.fm. |
| Лента свежих релизов | Показывает треки и альбомы за последние 30 дней, отсеивая будущие релизы и старые записи, недавно появившиеся в каталоге. |
| Фильтры по жанрам и типам релизов | Позволяет выбирать жанры и отдельно смотреть треки, альбомы или всё вместе. |
| Объединение повторяющихся релизов | Собирает одинаковые записи из разных сервисов в одну карточку. |
| Совместный рейтинг источников | Учитывает позиции релиза в разных чартах, избегая двойного веса Apple Music и iTunes. |
